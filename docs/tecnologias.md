# 🛠️ Tecnologias do Tibo

Este documento apresenta algumas das principais tecnologias, bibliotecas e ferramentas utilizadas ou exploradas durante o desenvolvimento do Tibo.

O conjunto tecnológico pode evoluir conforme novas necessidades surgirem e conforme o projeto avançar.

---

# 💻 Front-end

## React

O React é utilizado na construção da interface da aplicação.

Entre os conceitos explorados durante o desenvolvimento estão:

- Componentização
- Reutilização de componentes
- Organização da interface
- Gerenciamento de estados
- Renderização de dados
- Estruturação de páginas

---

## TypeScript

O TypeScript é utilizado para adicionar tipagem ao desenvolvimento da aplicação.

Durante o projeto são explorados conceitos como:

- Tipos
- Interfaces
- Tipagem de propriedades
- Estruturação de dados
- Maior previsibilidade durante o desenvolvimento

---

## JavaScript

O JavaScript também faz parte da base de conhecimentos utilizada durante o desenvolvimento.

A linguagem é utilizada para compreender conceitos fundamentais relacionados à lógica, comportamento da interface e desenvolvimento de aplicações web.

---

## Vite

O Vite é utilizado como ferramenta de desenvolvimento e build da aplicação.

Ele auxilia no ambiente de desenvolvimento, organização do projeto e geração das versões de produção.

---

# 🎨 Interface e experiência do usuário

## Tailwind CSS

O Tailwind CSS é utilizado na construção e estilização das interfaces.

Entre os conceitos explorados estão:

- Layout responsivo
- Organização visual
- Componentização de estilos
- Interfaces adaptáveis
- Desenvolvimento mobile-first

---

## Radix UI

Componentes e recursos do ecossistema Radix UI são utilizados como apoio na construção de elementos de interface.

A utilização de componentes reutilizáveis contribui para a organização e consistência visual da aplicação.

---

## Framer Motion

O Framer Motion é explorado para animações e transições na interface.

Entre os usos estudados estão:

- Animações
- Transições
- Interações visuais
- Experiência de navegação

---

# 🧭 Navegação

## TanStack Router

O projeto utiliza recursos de roteamento para organizar a navegação entre diferentes áreas da aplicação.

Entre os conceitos relacionados estão:

- Rotas
- Navegação entre páginas
- Estruturação de áreas da aplicação
- Proteção de rotas

---

# 🔄 Dados e estado

## TanStack React Query

O TanStack React Query é utilizado para auxiliar no gerenciamento de dados assíncronos.

Entre os conceitos explorados estão:

- Busca de dados
- Cache
- Atualização de informações
- Estados de carregamento
- Sincronização de dados

# 🗄️ Backend e banco de dados

## Supabase

O Supabase é utilizado como parte da infraestrutura de backend do projeto.

Entre os recursos explorados estão:

- Autenticação
- Banco de dados
- APIs
- Armazenamento de dados
- Controle de acesso
- Funções no backend

---

## PostgreSQL

O PostgreSQL é utilizado como banco de dados relacional.

Durante o desenvolvimento são explorados conceitos relacionados a:

- Modelagem de dados
- Relacionamentos
- Consultas SQL
- Estruturação de tabelas
- Integridade dos dados

---

# 🔐 Segurança

## Supabase Auth

Recursos de autenticação são utilizados para explorar:

- Cadastro de usuários
- Login
- Sessões
- Identificação de usuários
- Proteção de áreas da aplicação

---

## Row Level Security (RLS)

O projeto também explora conceitos de controle de acesso em nível de banco de dados.

Entre os temas relacionados estão:

- Permissões
- Controle de acesso
- Proteção de dados
- Regras baseadas no usuário autenticado

A segurança e as permissões são aspectos que exigem revisão contínua durante a evolução do projeto.

# ⚙️ Backend e funções

## APIs

O desenvolvimento do projeto envolve comunicação entre diferentes partes da aplicação por meio de APIs e serviços.

Entre os conceitos explorados estão:

- Comunicação entre Front-end e Back-end
- Requisições
- Respostas
- Tratamento de dados
- Integração entre serviços

---

## Edge Functions

O projeto possui estudos e implementações relacionadas a funções executadas no backend.

Esses recursos são utilizados para explorar a separação entre responsabilidades do cliente e operações que precisam ser executadas no ambiente do servidor.

# 📚 Aprendizado contínuo

O desenvolvimento do Tibo acompanha minha evolução como estudante de Engenharia de Software.

Por esse motivo, as tecnologias utilizadas no projeto não representam necessariamente domínio completo ou avançado de todas elas.

O projeto é utilizado como um ambiente prático para:

- Aplicar conhecimentos aprendidos
- Estudar novas tecnologias
- Resolver problemas reais de desenvolvimento
- Testar abordagens diferentes
- Melhorar a organização do código
- Compreender decisões técnicas
- Evoluir gradualmente a arquitetura

---

# 🔄 Evolução tecnológica

A stack do projeto pode sofrer alterações ao longo do tempo.

Novas tecnologias podem ser incorporadas quando fizer sentido para as necessidades do sistema e para a evolução do desenvolvimento.

A escolha de ferramentas busca considerar aspectos como:

- Curva de aprendizado
