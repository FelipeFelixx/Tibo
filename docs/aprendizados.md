# 📚 Aprendizados durante o desenvolvimento do Tibo

O desenvolvimento do Tibo faz parte da minha jornada prática como estudante de Engenharia de Software.

Ao construir o projeto, tenho a oportunidade de transformar conceitos estudados durante a graduação e em estudos complementares em experiências práticas de desenvolvimento.

Cada nova funcionalidade, problema encontrado ou decisão técnica representa uma oportunidade para aprender e aprofundar conhecimentos.

---

# 💻 Desenvolvimento Front-end

O desenvolvimento da interface permite explorar diferentes conceitos relacionados à construção de aplicações web.

Entre os aprendizados estão:

- Organização de componentes
- Reutilização de código
- Estruturação de páginas
- Responsividade
- Navegação entre diferentes áreas da aplicação
- Gerenciamento de estados
- Renderização de dados
- Experiência do usuário

A construção de uma aplicação maior também ajuda a compreender os desafios relacionados à manutenção e evolução de interfaces.

---

# 🧩 Organização de software

À medida que o projeto cresce, torna-se necessário pensar na organização do código.

Durante o desenvolvimento, são explorados conceitos como:

- Separação de responsabilidades
- Organização por funcionalidades
- Modularização
- Reutilização de componentes
- Manutenção de código
- Estruturação de serviços
- Evolução gradual da arquitetura

Esses conceitos ajudam a compreender que desenvolver software não envolve apenas escrever código, mas também pensar em como o sistema poderá evoluir ao longo do tempo.

---

# 🗄️ Banco de dados

O desenvolvimento do projeto também permite estudar conceitos relacionados a bancos de dados.

Entre os temas explorados estão:

- Modelagem de dados
- Relacionamentos
- Estruturação de tabelas
- Consultas
- Persistência de informações
- Integridade dos dados
- Organização das informações

A construção de funcionalidades sociais ajuda a visualizar, na prática, como diferentes entidades podem se relacionar dentro de um sistema.

---

# 🔐 Autenticação e segurança

A segurança é uma área importante no desenvolvimento de aplicações.

Durante o desenvolvimento do Tibo, são explorados conceitos relacionados a:

- Autenticação
- Sessões
- Identificação de usuários
- Controle de acesso
- Proteção de rotas
- Permissões
- Proteção de dados

Também são estudados conceitos relacionados à aplicação de regras de acesso na camada de dados.

A segurança é tratada como um processo contínuo e precisa ser revisada conforme o sistema evolui.

---

# 🔄 Integração entre sistemas

O desenvolvimento de uma aplicação completa também permite compreender melhor como diferentes partes de um sistema se comunicam.

Entre os conceitos explorados estão:

- Comunicação entre Front-end e Back-end
- APIs
- Requisições assíncronas
- Tratamento de respostas
- Estados de carregamento
- Tratamento de erros
- Sincronização de dados

Esses conhecimentos ajudam a compreender melhor o funcionamento de aplicações modernas.

---

# 🐛 Resolução de problemas

Ao encontrar um erro, o processo geralmente envolve:

```text
Identificação do problema
        ↓
Análise da possível causa
        ↓
Pesquisa e estudo
        ↓
Teste de soluções
        ↓
Implementação da correção
        ↓
Nova validação
