# 📊 Status do projeto

O Tibo é um projeto em desenvolvimento contínuo.

Por se tratar de uma plataforma em evolução, diferentes áreas do sistema podem estar em estágios distintos de implementação, revisão e planejamento.

Este documento apresenta uma visão geral do status do projeto de forma transparente.

---

# 🟢 Legenda

Para evitar confusão entre funcionalidades existentes e funcionalidades futuras, são utilizados os seguintes status:

- ✅ **Implementado** — funcionalidade existente e validada em determinado estágio do projeto.
- 🟡 **Em desenvolvimento ou revisão** — funcionalidade parcialmente implementada, em evolução ou passando por testes e melhorias.
- 🔵 **Planejado** — funcionalidade prevista para etapas futuras.

A presença de arquivos, componentes ou estruturas relacionadas a uma funcionalidade não significa necessariamente que ela esteja completamente concluída.
